# 使用文档

本说明面向日常使用：登录控制台、管理会话与配置、在 QQ 里与 AI 交互、以及常见操作怎么做。

## 1. 登录

1. 打开 `http://127.0.0.1:21001/`；
2. 输入用户名、密码、验证码；
3. 管理员可管理全部页面；编辑者（editor）只能访问知识库与黑话。

登录失败会锁定来源 IP 一段时间；忘记密码可用 `web/management/` 下的脚本或数据库重置。

## 2. 页面一览

| 页面 | 用途 |
| --- | --- |
| 概览 | 运行状态、会话数、用量图表（24 小时 / 7 天 / 全部 / 指定某天，可按会话过滤） |
| 会话 | 各群/私聊的未读、唤醒配置、唤醒次数、最近回复；可刷新、标记已读、重置上下文、手动唤醒 |
| 峰谷 | 按时间段设置回复概率、推理强度、主动话题、发送上限、估算价格 |
| 知识库 | 第五人格资料的新增/编辑/停用/删除与预览 |
| 黑话 | 群聊黑话候选的确认、编辑、停用、删除、学习 |
| 工具 | 按功能分组的 AI 工具开关，可搜索、全开/全关、保存并热重载 |
| 日志 | 桥接/控制台运行日志 |
| 表情 | 收藏表情列表、备注/标签、设为常用、只看常用、从 QQ 同步 |
| 人格 | 角色文件选择与当前角色 |
| 预设 | DSH 聊天预设（`qq-chat-v2`）查看/编辑 |
| 令牌 | 各会话的令牌状态、生成/撤销 |
| 用户 | 控制台账号管理、改密、启停 |
| 配置 | 全部配置项，按功能分组，可热更/需重启有标记 |
| 设置 | 白名单、管理员 QQ、会话时长等常用设置 |

## 3. 用量统计

概览页顶部：

- 范围：近 24 小时（按小时）、近 7 天（按天）、全部（按天，最多 180 天）、指定某天（按小时）；
- 会话下拉可只看某个群或私聊；
- 每根柱子鼠标悬浮显示时间、tokens、费用、所属峰谷；
- 价格口径：当前时段配置的价格 → 自定义模型价 → 官方人民币价；峰谷页可按时段覆盖价格。

管理员也可以在 QQ 里查：

- 私聊机器人："查一下最近七天的用量"
- 群里 @ 机器人："看看今天 group:xxx 用了多少"

对应工具 `qq_usage`，支持 `24h / 7d / all / day` 与 `conv` 过滤，返回摘要与逐小时/逐天明细。

## 4. 配置修改

"配置"页按功能分组：表情包与自动补图、发送节奏与连发、唤醒与潜水、等待与合批、上下文与记忆、媒体处理、语音、反馈、其它仿真参数，以及 DSH/知识库/黑话/联网/控制台/安全/价目表等。

- 绿色"可热更"：保存后立即生效；
- 橙色"需重启"：写入配置文件，但需要重启桥接；
- 概率字段用百分比填写（如 5% 而非 0.05）；
- 毫秒字段用秒（或小时）填写，保存时自动换算。

发送额度（峰谷页）：

- “合计·每分钟 / 合计·每小时”约束**除管理员私聊外的全部聊天**；
- “分群限额”可给指定群追加单独限制（一个名单可填多个群号），未列出的群只受合计约束；
- 超过任一额度时，该群**暂停唤醒**——不调用模型、不消耗 token，未读消息保留；额度恢复后自动继续下一次唤醒。

常用调整：

- 自动补图太频繁：配置 → 表情包与自动补图 → 自动补图概率（当前 5%），改成 2% 或 0；
- 回复太频繁：峰谷页调低"回复概率"，或配置 → 发送节奏调低每小时上限；
- 主动开话题：峰谷页"主动开话题"或唤醒与潜水的推荐值。

## 5. 工具开关

"工具"页按 5 组展示所有 `qq_*` 工具：发送与互动、读取与查询、表情与媒体、记忆与知识、管理（仅管理员）。

- 关闭后桥接立即拒绝该工具；
- MCP 侧工具注册在 DSH 启动时决定，完全生效需要重启 DSH；
- 管理员工具（改群名片/资料卡/用量/配置）带"仅管理员"标记。

## 6. 表情库

- "表情"页可看全部收藏、搜索、编辑备注/标签；
- 点"☆ 设为常用"标记常用表情，AI 选图时会优先使用（★ 显示）；
- "只看常用"筛选；
- "从 QQ 同步"拉取最新收藏；
- 自动补图概率、冷却、注入提示词条数在"配置 → 表情包与自动补图"。

## 7. 在 QQ 里使用

### 私聊

- 直接发消息即可，机器人会回复；
- 管理员私聊可用管理工具：改昵称/签名、查用量、改配置、加白名单等。

### 群聊

- 默认需要 @ 机器人、叫名字、提问、拍一拍或命中关键词才会唤醒（取决于该会话的唤醒配置）；
- 群里管理员 @ 机器人后 5 分钟内，可以执行一次管理操作（改群名片、资料卡、查用量、改配置）；
- 想让它主动参与，可在"峰谷"页调高主动概率，或在"会话"页把唤醒配置改为活跃。

### 常用管理指令（管理员）

在私聊或群里 @ 机器人后说：

- "把群 123456789 加进白名单"
- "把群名片改成 小鲸鱼"
- "昵称改成 超级小鲸鱼，签名改成 今天也在摸鱼"
- "查一下这个群今天的用量"
- "把自动补图概率改成 0.02"

机器人会调用对应工具；非管理员或超过授权时间会被拒绝。

## 8. 会话与会话重置

"会话"页可查看每个群/私聊的状态：

- 未读、唤醒配置、唤醒次数、最近回复；
- 标记已读；
- 重置上下文（清空该会话的 DSH 会话，下条消息重新建会话）；
- 手动唤醒（按当前唤醒配置触发一次）。

AI 卡住、长时间不回、工具报连接错误时，优先在这里重置会话。

## 9. 异常与会话恢复

- AI 处理出错时，错误提示只发到**管理员私聊**，不再发到群里；同一会话 10 分钟内最多提示一条；
- 如果连续 3 次出现 400/上下文类错误，桥接会**自动重建该群的 DSH 会话**（保留未读消息与唤醒配置），并私聊通知管理员；
- 仍无法恢复时，在「会话」页对目标群执行「重置会话上下文」，或私聊管理员用 /reset（会重建 DSH 会话）。

## 9. 知识库与黑话

- 知识库用于第五人格资料（角色/皮肤/赛事/术语），AI 在相关话题会检索并参考；
- 黑话库记录群聊常用梗，AI 可查询、提交候选，管理员确认后生效；
- 两个页面都支持搜索、编辑、停用、删除。

## 10. 安全与注意事项

- 控制台只在本机使用，不要把 21001 暴露到公网；
- 管理操作只对管理员 QQ 生效；
- 控制台密码为明文存储，数据库和备份要保管好；
- 白名单之外的消息不会处理；
- 修改 DSH 地址、数据库、端口等"需重启"项后，记得重启对应服务。
